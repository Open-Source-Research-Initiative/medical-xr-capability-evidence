# Join the Medical XR project

Anyone can read, download and fork this public OSRI project. Start with the [locked question and current state](../README.md), [methods](../methods/README.md), [open data](../data/README.md) and [worked source trace](../examples/README.md). OSRI lists this project as [OSRI-0001](https://github.com/Open-Source-Research-Initiative/osri/blob/main/projects/projects.csv).

Use [Issues](https://github.com/Open-Source-Research-Initiative/medical-xr-from-capabilities-to-sustainable-use/issues) to offer help or discuss a bounded task. Choose **Join the project** to describe your interests and availability. A public contribution or discussion does not require organization membership. Cole / @ajhcs coordinates assignments and any repository permissions; do not publish contact details or credentials.

Useful contributions include:

- Check documentation, data links and reproducibility instructions.
- Review the search-provenance gaps or the proposed feasibility and validation designs.
- Improve the public analysis tools with a small, tested pull request.
- Offer expertise in clinical applications, XR engineering, evidence synthesis, implementation or health economics.
- Volunteer for a bounded source check after agreeing the task with Cole. Read the [human verification procedure](human-verification.md) before opening AI decisions, save your own assessment first and disclose prior exposure.

Reading the public decision tables or full archive can expose a prospective reviewer to AI assessments. Disclose that exposure; do not later describe the same review as blinded. The archive deliberately preserves historical disagreement and unfinished work.

Scientific screening remains paused. Joining the project does not authorize restarting workers, changing the locked question, replacing original assessments or presenting provisional decisions as validated findings. Follow [CONTRIBUTING.md](../CONTRIBUTING.md), preserve original IDs and chronology, and record sources, checks, assistance and remaining uncertainty. Third-party notices and terms remain applicable when contributing source material.
