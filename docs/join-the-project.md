# Join the Medical XR project

Anyone can read, download and fork this public OSRI project. Start with the [five-minute guide](quickstart.md), [locked question](../README.md), [methods](../methods/README.md) and [data versions](active-screening.md#which-data-version-am-i-viewing). OSRI lists this project as [OSRI-0001](https://github.com/Open-Source-Research-Initiative/osri/blob/main/projects/projects.csv). Reading, proposing a task and submitting a pull request need no organization membership.

For screening, choose a package from the [35 source issues](../data/runs/2026-11-17/README.md) linked by [tracker #9](https://github.com/Open-Source-Research-Initiative/medical-xr-from-capabilities-to-sustainable-use/issues/9). Comment with one unclaimed batch or a smaller exact-ID task, your intended contribution and actual identity/model assistance. Coordinate the claim before duplicating work. The packet command and submission requirements are in the [screening workflow](screening-workflow.md#claim-a-contribution); the five frozen inputs are available in the public evidence release. Some packages already contain saved work awaiting checks, so check their issue before starting fresh assessments.

Other contributions include:

- Find a missing source or publication-date record and link the exact publication ID and evidence.
- Check documentation, links, packet reconstruction or reproducibility instructions.
- Review search-provenance gaps or the proposed feasibility and validation designs.
- Improve public tools with a bounded, tested pull request.
- Offer clinical, XR engineering, evidence-synthesis, implementation or health-economics expertise through the **Join the project** [issue form](https://github.com/Open-Source-Research-Initiative/medical-xr-from-capabilities-to-sustainable-use/issues/new/choose).

Cole / @ajhcs coordinates scientific assignments and repository permissions. Contributors submit separate proposed results; only the coordinator writes canonical ledgers. Preserve original IDs, assessments, memberships, samples and correction chronology. Joining does not authorize changes to the locked question, eligibility criteria or scientific scope. Record actual sources read, attempts, access limits, assistance, exposure and unresolved facts; respect source terms and avoid personal contact details or credentials. [CONTRIBUTING.md](../CONTRIBUTING.md#make-a-first-contribution) explains branches and pull requests.

Required human scientific review occurs after all model work and audits have produced the final PI packet. Model-stage results remain provisional and may be integrated after appropriate model/source checks and required CI under Cole's 17 November instruction. This review timing is a documented project-specific difference under OSRI-0.1.0. Neither closing an ordinary issue as model-complete nor passing tests is PI sign-off. [Issue #22](https://github.com/Open-Source-Research-Initiative/medical-xr-from-capabilities-to-sustainable-use/issues/22) records the final human decision when it occurs.

If you voluntarily offer an independent human source check, read the [source-first procedure](human-verification.md) before opening AI decisions, examples or the full archive. Save your own assessment first and disclose prior exposure. Reading the public decisions can prevent a later claim of blinded review. Such voluntary checks are separately recorded and do not block model work; the existing source-check issue #1 is deferred to the final PI phase. No human verification or scientific validation is currently established by the agent record.
