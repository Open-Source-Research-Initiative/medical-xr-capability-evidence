# Proposed human source checks

This directory is for separate proposed human-review submissions. No completed human result is present. Files submitted here do not by themselves change canonical decisions, verification counts or scientific acceptance.

For the first bounded task, start with [issue #1](https://github.com/Open-Source-Research-Initiative/medical-xr-from-capabilities-to-sustainable-use/issues/1) and [the source-first procedure](../../docs/human-verification.md). Cole coordinates the assignment. Read the source and rules, save your own assessment, then compare the existing AI route. Disclose prior exposure and any assistance; an agent-generated assessment is not a human attestation.

Copy [human-verification-template.csv](../human-verification-template.csv) into a new file named `P0000314-your-github-login.csv` in this directory. Keep its header and save one proposed result row. Use your actual reviewer identity as you wish it to be publicly attributed. Cite source/version/sections read, your own reasoning, limitations, disagreements and attestation. Do not mark unread or inaccessible evidence as verified.

Submit the new file in a pull request, link issue #1, and state what you personally checked. Keep the original blank template, original ledgers and count/pause files unchanged. A maintainer reviews the proposed result and records its acceptance or unresolved points separately. Scientific screening remains paused; this submission path does not authorize restarting workers or changing research labels.
