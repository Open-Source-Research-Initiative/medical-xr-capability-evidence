From a fresh public clone with Python 3.12 or later, run:

```
python scripts/show_example.py
```

No packages, account, network request, original workspace or restricted inputs are required. The command validates the authored trace's fields and prints its recorded route and limits. It does not classify papers or independently establish that the route is scientifically correct. Editing the record changes the example; it never updates research ledgers.
