The user instruction in `11 - Calibration and full inventory screening prompts.md` states: “Unavailable text remains pending, not excluded.” This operational correction takes precedence over earlier title-only exclusion handling. It does not change the locked question or medical scope.

A blank inventory abstract is a retrieval locator, not proof that source text is unavailable. Each reviewer must check their entire saved pass and document any sufficient source text actually accessed. Where only title/metadata are available, current eligibility is UNCERTAIN and access/eligibility remain pending. A title-supported patent, news, review or protocol context classification is retained independently; missing text does not erase that context route. Source-accessed exceptions must name the source and inspected extent. Merely knowing a URL is insufficient.

Original independent decisions remain immutable. Append-only reviewer corrections and superseding adjudication files expose the current pending status. Counts distinguish initial record-level assessments saved, unscreened IDs, assessed IDs with text/access pending, and human verification pending. Queue membership may overlap: a context candidate with missing text belongs in both the context and uncertainty queues. Count unique IDs for overall coverage, never add overlapping queue counts.

All earlier and future title-only records are subject to this rule. Missing full text alone does not prevent an otherwise supported title/abstract advancement; full-text retrieval gaps remain separately pending. No human verification is implied by any AI source-access check.
